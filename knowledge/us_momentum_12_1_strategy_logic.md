# 美股动量轮动策略（12-1 动量 + 21 个交易日调仓）

> 来源：本仓库 `scripts/backtest_engine.py` 在 228 只美股、12 年日线上的完整检验结果。
> 口径：21 个交易日调仓、等权前 5 只、扣 8bps 成本、139 个调仓期。

---

## 一句话

买"过去一年涨得最猛、但最近一个月歇过一口气"的股票，等权持有 5 只，每约一个自然月按同一规则重排一次；
掉出动量前 5 名就卖掉换掉。**不择时、不止损、不加任何形态过滤。**

## 为什么是这个（而不是 MACD / KDJ / 布林 / 九转）

同一口径下实测过的全部方案：

| 策略 | CAGR | HAC t |
|---|---|---|
| **12-1 动量（本策略）** | **34.3%** | **2.36** |
| Minervini 趋势模板 | 24.5% | < 2 |
| 高低点/杯柄形态（HTF/VCP） | 18.8% | < 2 |
| Clenow 动量 | 18.7% | < 2 |
| 均线回调买入 | 13.7% | < 2 |
| 海龟 55 日突破 | 9.3% | < 2 |

- 本策略完整指标：CAGR **34.3%**、Sharpe **1.12**、最大回撤 **-28.4%**、跑赢 SPY **+15.4%/年**、
  HAC **t = 3.58**、bootstrap **p = 0.008**、**12 年里 11 年为正**、样本内 t=3.00 / 样本外 t=2.34。
- 已排除"口径不公"：持有期扫 5/10/21/63 天它每种都第一；剔除高价股切片后排序不变。
- **6 套海外知名系统没有一套跑过它**，全部 t < 2。⇒ 最简单的最强。

## 买入逻辑（可直接粘贴）

```
标的池：美股，只做你熟悉且有流动性的名字（建议 50 只以上，覆盖多个板块）。

在那一天美东收盘后（用已经收完的日线，不要用盘中未完成的那根）：
1) 计算每只股票的 12-1 动量：
   M = 收盘价(21 个交易日前) / 收盘价(252 个交易日前) - 1
   （也就是：从一年前到今天，但刻意跳过最近 21 个交易日）
2) 把全池按 M 从大到小排序，取前 5 名。
3) 这 5 只等权买入，每只占总仓位 1/5，市价成交（小账户用"按金额"碎股下单）。
4) 调仓频率：每 21 个交易日（约 1 个自然月）执行一次，只在调仓日下单，不做盘中触发。
5) 若某只 M ≤ 0，该名额留现金，不拿其他票替代（不要为了"满仓"去换便宜的票）。
```

## 卖出逻辑（可直接粘贴）

```
每 21 个交易日，在调仓日重新计算全池 12-1 动量：
1) 原持仓中跌出前 5 名的 —— 全部市价卖出。
2) 仍在前 5 名内的 —— 继续持有，并重新调回等权（每只 1/5）。
3) 不设个股止损，不因大盘下跌减仓，不做任何择时判断。
4) 标的停牌/退市导致无法交易时，该名额转为现金。
```

## 明确"不要加"的清单（都实测过，加了更差）

| 想加的东西 | 实测结果 |
|---|---|
| 市场择时门控（SPY > 200 日均线、回撤 < 5/10/15%、波动率 < 20/25%） | 6 种**全部同时降低收益和 t**。无门控在各条轴上最好（始终满仓是验证过的配置） |
| 波动率缩放（把信号除以实现波动） | t 从 **3.58 → 1.03**，唯一差别就是那个除法 |
| MACD / KDJ / BOLL / 九转 / 形态过滤器 | 6 套知名系统全部跑输（见上表），全部 t<2 |
| 质量 / 低波动因子做排序或过滤 | 单独无超额（t ≈ 0.3）；与动量秩相关仅 0.118（信息不同但不互补）；做过滤总是同时降收益和 t |
| 个股止损 | 未在证据中；本策略的退出机制**就是排名变动**。要止损请先单独回测验证 |

> 一句话原则：**任何新增的复杂度都必须自带统计证据，否则默认拒绝。**
> 这个项目已经在 Clenow 过滤 / Minervini 过滤 / 质量门控 / 市场门控上四次得出同一个结论。

## 如果你的工具只能逐只声明标的（富途策略画布 / FTQuant 就是这种）

画布类工具无法"扫全市场选前 5 名"，只能用单标的规则逼近。可粘贴版本：

**买入：** 日线已收完，且 ① 12-1 动量 M > 0（`收盘价(21日前) / 收盘价(252日前) - 1 > 0`）
② 收盘价 > 200 日均线 ⇒ 市价买入该标的 1/5 计划仓位。

**卖出：** ① M ≤ 0 或 ② 收盘价跌破 200 日均线 ⇒ 全部清仓。

⚠️ **必须知道代价**：加了个股趋势过滤后，实测 CAGR 从 34.3% 掉到 29.9%（回撤改善 3.2pp，
是权衡不是改进）。**因为这套策略的收益主要来自"排名前 5"这个横截面比较，单只判断会丢失它。**
所以：**选股留在本仓库（`scripts/daily_pick.py`），富途画布只做执行**（挂单 + 券商侧止损）。

## 仓位与账户规模（$3,000 档实测）

- 推荐：**5 只等权 × $600、按金额碎股、每 21 个交易日调仓**。
  净年化 **44.5%**、最大回撤 **-31.6%**、最差年 -15.0%、中途可能浮亏到约 **$2,050**。
- 换 top-10 的对照：净 32.7% / 回撤 -28.2% ⇒ **用回撤换收益**，按承受力选。
- 成本按笔数不按金额：$1/笔在 $3,000 上是 **1.14%/年**（top-5）vs 2.31%/年（top-10）；
  同样的笔在 $15 万账户只有 0.05% ⇒ 小账户的成本劣势是结构性的。

## 已知风险（必须知道）

- **幸存者偏差**：池子是手工维护的当下成分股，历史上已退市/暴跌出局的票不在池内，实际收益会打折。
- **集中度**：纯动量在板块主导的行情里必然堆在一个板块（历史上前 10 里有 6 只是半导体）。
  这**不是 bug**，但组合会承载单一产业周期的风险。
- **回撤**：-28% ~ -32% 的回撤会真实发生，最差年份 -15%。
